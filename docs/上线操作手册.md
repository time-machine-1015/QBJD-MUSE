## 第 0 步 · 把服务端代码放上 GitHub（约 1 分钟）

原因：Deno Deploy 要从你的仓库里取 `server/write-api.js`。

1. 打开 <https://github.com/time-machine-1015/QBJD-MUSE>
2. 点 **Add file → Upload files**
3. 在文件资源管理器里打开 `C:\Users\ASUS\Desktop\QBJD-MUSE`，把 **`server` 这个文件夹**拖进网页
   - 只拖 `server` 文件夹；
   - **不要**拖 `index.html`、`cloud.js`、整个项目（新版本前端等验证完再上）
4. 页面下方 **Commit changes → Commit changes**
5. 刷新仓库，确认能看到 `server/write-api.js`

`server/` 里没有任何密钥，可以公开。

## 第 1 步 · 建数据仓库并打开 Pages（约 1 分钟）

1. 打开 <https://github.com/new>
2. **Repository name** 填 `QBJD-MUSE-data`
3. 选 **Public**；下面的 Add a README / .gitignore / license **都不要勾**
4. **Create repository**
5. 进仓库 → 顶部 **Settings** → 左侧 **Pages**
6. **Source** 选 `Deploy from a branch`；**Branch** 选 `main` + `/ (root)`；**Save**
7. 顶部会出现 `Your site is live at https://time-machine-1015.github.io/QBJD-MUSE-data/`
   - 如果还没出现也正常：仓库现在是空的，等我迁照片进去就生效

## 第 2 步 · 建一个"只够用"的 token（约 2 分钟）

1. 打开 <https://github.com/settings/tokens?type=beta>
2. **Generate new token**
3. **Token name**：`qbjd-write-api`；**Expiration**：1 year
4. **Resource owner**：`time-machine-1015`
5. **Repository access**：`Only select repositories` → 只勾 **`QBJD-MUSE-data`**
6. **Repository permissions** → 找到 **Contents** → 改成 **Read and write**（其它全部保持 No access）
7. **Generate token** → 复制 `github_pat_` 开头那串（只显示一次）

> ⚠️ 这串**只填进下一步 Deno 的环境变量**，不要发给我、不要写进任何文件或群聊。

## 第 3 步 · 部署 Deno Deploy（约 5 分钟）

1. 打开 <https://dash.deno.com/> → **Continue with GitHub** → Authorize
2. **New Project** → **Deploy from GitHub**
   - 若提示授权，允许 Deno 访问你的仓库，勾选 `QBJD-MUSE`
3. 选仓库 `QBJD-MUSE`，分支 `main`
4. 构建设置：
   - Framework preset：**None / Other**（没有就跳过）
   - Build command：**留空**
   - Install command：**留空**
   - **Entry point**：`server/write-api.js`
5. **Environment Variables** 一次加 8 个（见下表）
6. 点 **Deploy / Create Project**，等 20~40 秒
7. 完成后页面顶部显示地址，形如 `https://qbjd-muse-write.deno.dev`
8. 浏览器打开 `https://你的地址/api/ping`
   应该看到：`{"ok":true,"service":"qbjd-muse-write-api","users":8,...}`
9. **把这个地址发我**

> 界面和描述不一样就截图发我，我按你看到的界面指路。

## 第 4 步 · 吊销旧 token（约 1 分钟）

1. 打开 <https://github.com/settings/tokens>
2. 先看 **Tokens (classic)**：找到当初给这个 App 建的那个（很可能是列表里唯一一个），点 **Delete / Revoke**
3. 列表里没有的话，再看 **Fine-grained tokens**，同样删掉旧的

注意：吊销后，线上旧版的点赞/评论/上传会立刻失效（浏览不受影响）——这是预期的，新后端马上接管。
